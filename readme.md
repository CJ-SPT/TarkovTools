# Tarkov Tools Alpha

This is a mod designed to make you feel like a modder yourself. It provides you with the tools to be able to seemlessly
edit server data and functionality at a relatively low level easily. 

# Current Features

## Web Editor
- A web editor fully integrated into the server makes this simple to use in real time available at: https://127.0.0.1:6969/tarkovtools

## Presets
- Create, load, apply and share presets

## Locale Editor
- Edit any locale available in the server

## Trader Editor (Current Focus)
- Edit any trader data in the server (Limitations apply WIP feature)

## MongoId Generator
- Generate a single or multiple MongoIds at a time
